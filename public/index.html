Surreal Investigate

Set up large data collections so AI can retrieve relevant evidence, uncover patterns, and produce actionable insights. Surreal indexing gives your assistant durable structured memory across text, spreadsheets, PDFs, and mixed file sets.

Workflow + File Handling

Guidance: Follow this sequence: Upload → Generate Feature Plans → Index → Ask Questions. Files are copied to uploads/<cacheId>/, index artifacts are written under indexes/<cacheId>/, and the index manifest is indexes/<cacheId>/manifest.json.

  1. Credentials: add OpenRouter key + model id (optional for AI-assisted planning/summaries).
  2. Upload: attach files to cache (selection alone does nothing).
  3. Feature Plans: generate extraction mapping + lexicon + table intents.
  4. Index: writes structured rows to SurrealDB tables.
  5. Ask: run retrieval + reasoning on indexed data.

API Credentials (OpenRouter)

Guidance: OpenRouter is the default provider here so you only need API key + model id. Choose either local input (quick testing) or .env loading (recommended).
